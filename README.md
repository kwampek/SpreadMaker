

# 🚀 Crypto Arbitrage Bot

Крипто-арбитраж бот для автоматического мониторинга цен на разных биржах и рассылки уведомлений о возможных арбитражных возможностях через Telegram.

## 📌 Возможности

* 🔍 Мониторинг цен криптовалют на нескольких биржах (например: Binance, Bybit, OKX, KuCoin).
* 📊 Поиск арбитражных возможностей между биржами.
* ⚡ Быстрая проверка разницы в ценах и фильтрация по заданному проценту прибыли.
* 🤖 Уведомления через Telegram-бота с деталями сделки:

  * Валюта
  * Биржа для покупки и продажи
  * Разница в процентах
  * Потенциальная прибыль



## 🛠️ Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/username/crypto-arbitrage-bot.git
cd crypto-arbitrage-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл **.env** в корне проекта и добавьте туда:

```
OPENAI_API_KEY=""

EXCHANGE_BASEURL=""
EXCHANGE_API=""
EXCHANGE_SECRET=""
EXCHANGE_SEP=""
```

в файл internal/telegram_bot/telegram_bot.go добавить API ключ для телеграм бота

---

## ▶️ Запуск

```bash
go cmd/main.py

```

Бот будет автоматически отслеживать цены и присылать уведомления в Telegram, если обнаружит разницу выше заданного процента.

---
